Для запуска данной лабораторной работы предварительно нужно настроить эмуляцию серийный портов.

## Настрока под Linux
Для Linux это делает с помощью утили socat

sudo apt install socat
socat -d -d PTY,link=/tmp/ttyV0,raw,echo=0 PTY,link=/tmp/ttyV1,raw,echo=0

В консоль будет выведенно два порта в формате /dev/pts/\<number>

Первый надо передать эмулятору, он будет использоваться для записи.

Второй надо передать логгеру, он будет использоваться для чтения.

## Настрока под Windows
Для эмулирования портов на windows есть бесплатная утилита com0com

К сожалению, утилита не поддерживается с 2018 года, поэтому ее драйверы устарели и не проходят проверку Windows. Поэтому для запуска утилиты надо отключить проверку подписи сертификатов.

Порты будут иметь формат COM1 и COM2. Первый передаем эмулятору, второй логгеру
